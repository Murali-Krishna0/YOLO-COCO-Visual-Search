# 🚀 YOLO-COCO-Visual-Search

A lightweight Computer Vision Powered Search Engine built using YOLOv11 and the COCO dataset.
Search images by detected object classes like laptop, truck, wine glass, tennis racket, etc.


# 🚀 Features

🔍 Search images using object names
⚡ YOLOv11-based object detection
🖼️ Bounding box visualization
🎯 OR / AND class filtering
📊 Object count thresholds
📁 Metadata loading support
🌙 Clean Streamlit UI


# 🛠️ Tech Stack

-> Python
-> YOLOv11
-> OpenCV
-> Streamlit
-> PyTorch
-> COCO Dataset

cd yolo-coco-visual-search

pip install -r requirements.txt


# ▶️ Run the App

streamlit run app.py
